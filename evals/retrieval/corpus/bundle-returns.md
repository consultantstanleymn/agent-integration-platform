# Bundle return policy

## Bundle return condition rule

A bundle is two or more items sold under one bundle SKU at a single discounted price.

To return a bundle, the customer must send back every component in saleable condition with the original packaging. A missing or damaged component changes the refund amount.

A bundle that includes a tent or sleeping bag must be returned clean and dry.

## Missing bundle component deductions

If a component is missing, the refund is the bundle price minus the current full listed price of the missing component.

If the deduction is larger than the bundle price, no refund is issued. The customer service agent explains the deduction before the return is processed.

For example, a bundle with TNT-4421 and SLP-12 must include both items. The missing SLP-12 deduction is the listed price of that sleeping bag.

## Partial bundle replacement

A bundle cannot be partially returned for a cash refund. If one component is defective, OutdoorCo may replace only that component.

If the same component is not available, the customer receives store credit equal to 60 percent of that component's current listed price.

Partial replacement does not reset the return window for the other bundle items.

## Bundle SKU and proof of purchase

The customer must provide the bundle SKU from the order confirmation or the packing slip.

Agents must not split a bundle into separate item SKUs for a return or a price adjustment. The bundle price is the only price used for return math.

The bundle SKU remains the reference for the whole transaction even when a single component is replaced.

## Bundle return shipping and waybill

If the wrong bundle shipped or a component arrived damaged, OutdoorCo provides a prepaid waybill.

For a change-of-mind bundle return, the customer pays return shipping. A missing component fee is calculated after the return arrives at the returns center.

If the customer uses the wrong waybill, processing may be delayed by up to 5 business days.

## Bundle promotion adjustments

If a bundle was sold with a free gift, the free gift must be returned or its full listed price is deducted from the refund.

If the bundle price drops within the price adjustment window, the same bundle SKU must still be in stock to qualify for an adjustment.

A bundle return does not qualify for a price adjustment on individual components.
