# OutdoorCo International Returns Policy

## International return window

International customers must start a return within 30 days of delivery. The same condition rules apply as in the domestic returns policy. Final sale items are not returnable from international orders.
The return window is based on the delivery scan, not the order date. A customer starts a return by contacting support with the order number and the product code.

## Duties and taxes

OutdoorCo does not refund import duties, taxes, or customs fees paid by the customer. Customers may be able to claim a refund of duties from the local customs authority with a proof of return.
If OutdoorCo ships the wrong item, OutdoorCo will provide additional documentation to support a duty refund request. The documentation includes the original order value and the reason for return.

## Return shipping and waybill labels

International returns do not include prepaid return labels unless OutdoorCo shipped the wrong item or the item arrived defective. The customer pays return shipping and customs charges in that direction.
The customer must use a carrier that provides a waybill or tracking number. The waybill number must be shared with support before the package is sent.

## Currency and refund exchange rate

OutdoorCo refunds in the original purchase currency. For card payments, the card issuer sets the exchange rate. OutdoorCo does not control currency conversion changes between purchase and refund.
Store credit for international returns is issued in the customer's account currency when supported. If the account currency is not supported, OutdoorCo issues store credit in the original order currency.

## Restricted international items

Fuel canisters and opened consumable items cannot be returned by international customers. Opened water filters are returnable only for a defect and require a photo.
Pressurized items must not be shipped back. OutdoorCo may issue a refund without return when a pressurized item is defective and the customer provides photo proof.

## Chargeback prevention

International customers should contact OutdoorCo before filing a chargeback. Support can provide waybill instructions, replacement options, and documentation. A chargeback filed while a replacement is in transit may be disputed with tracking records.
OutdoorCo responds to chargebacks with order details, return records, and delivery confirmation within 7 business days.
